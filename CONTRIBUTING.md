# Участие в разработке

Установите Node.js 22+, выполните npm ci, npm run build, npm test и npm run test:browser. Для браузерных проверок установите Chromium командой npx playwright-core install chromium или задайте CHROMIUM_PATH. Проверьте комплект Groovy по инструкции установки.

Сохраняйте зависимости только для разработки. Перед отправкой изменения пересоберите оба файла dist, обновите документацию публичного поведения и регрессионный тест затронутого сценария. Проверяйте ввод только на синтетических проекциях. Для новых видов графиков укажите требования к измерениям, пустое состояние и связь с исходными строками.
