# Сообщение о проблеме безопасности

Укажите версию Studio, браузер, тип операции и ожидаемое поведение. Используйте вымышленные атрибуты и объекты. Для конфиденциального отчёта используйте приватное сообщение об уязвимости через раздел Security репозитория, если владелец включил эту возможность, или согласованный внутренний канал сопровождения.

Для публичного issue достаточно описания класса ошибки и синтетического регрессионного теста. Корпоративные выгрузки, снимки рабочих карточек, внутренние адреса и учётные данные не нужны. Технические границы доверия изложены в [модели безопасности](docs/security.md).
