# Установка и первый запуск

1. Скачайте архив проекта с GitHub и распакуйте с сохранением каталогов.
2. Откройте `demo/index.html` в современном браузере. Сразу откроется дашборд синтетических обращений. Закройте окно и выберите сотрудников, оборудование или другой объём. Кнопка измерения выводит время генерации и открытия отдельно.
3. Для установки выберите один файл из `dist/`. Обычную версию удобно изучать в DevTools, минифицированную удобно разместить в локальных статических ресурсах NSD.
4. Загрузите его один раз на странице до вызова операции. Вызовите `NSDAnalytics.open(rows, config)` после проверки серверных прав. Способ регистрации ресурса и JS-операции определяет технолог установки. См. [интеграцию](nsd-integration.md).

Для демонстрации также подходит локальный HTTP-сервер. В корне архива выполните `python3 -m http.server 8000 --bind 127.0.0.1` и откройте путь `/demo/` на этом порту. Режим file:// зависит от ограничений конкретного браузера для загрузок и буфера обмена. Приложение сообщает об ошибке и предоставляет TSV.

## Сборка из исходников

Потребуется Node.js 22+ на машине разработчика. В каталоге проекта выполните:

```sh
npm ci
npm run build
npm test
npx playwright-core install chromium
npm run test:browser
npm run bench
```

Для уже установленного Chrome/Chromium укажите переменную `CHROMIUM_PATH` с путём к исполняемому файлу. Браузерный benchmark запускает `node benchmarks/browser.mjs`. Ключ `--record` записывает новые измерения. Без ключа сценарии выводят результат в консоль. Отдельный пример и проверки Groovy запускает `GROOVY_JAR=/path/to/groovy-all-2.4.21.jar bash scripts/test-groovy.sh`.

Сборка воспроизводима из зафиксированных версий npm. Промышленная загрузка dist, открытие демо, вычисления и экспорт обходятся без npm, сетевых запросов и дополнительного сервера.
