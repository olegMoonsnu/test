# NSD сообщает «Ошибка проверки подписи»

Каталог отклонил файл на этапе проверки подписи. Сборка проекта создаёт обычный JavaScript `dist/nsd-analytics-customization.js` без подписи для Naumen. Успешная проверка в браузере подтверждает работу интерфейса. Для установки через каталог требуется файл с подписью, которую принимает ваша NSD.

## Как установить через каталог

1. Обратитесь в поддержку NAUMEN. Укажите полный номер сборки NSD из сведений о системе и приложите исходную сборку Studio по запросу. Пример обращения:

   > При загрузке JavaScript через «Каталог файлов кастомизации» на Naumen Service Desk 4.17 получаем «Файл не может быть загружен. Ошибка проверки подписи». Хотим установить собственную аналитическую панель в интерфейс оператора. Какой порядок согласования и подписания клиентской кастомизации предусмотрен для нашей сборки? Можете ли вы подготовить совместимый файл или указать доступный заказчику штатный способ подписи?

2. Когда получите совместимый подписанный файл и указания для своей версии, используйте полученный файл без редактирования. В публичном руководстве путь к форме такой: **Настройка системы → Каталог скриптов и модулей → Каталог файлов кастомизации → Добавить файл**. Место применения для Studio — **Интерфейс оператора**.
3. После успешной загрузки на тестовом стенде обновите страницу оператора. Если согласованный файл включает кнопку проекта, нажмите **Аналитика → Открыть демо**. Контрольный результат — три вымышленные заявки и среднее время 60 минут.

NAUMEN направляет заказчиков в поддержку по вопросам добавления файлов кастомизации. Порядок самостоятельной подписи для 4.17 в публичном описании каталога не указан. [Каталог файлов кастомизации](https://www.naumen.ru/docs/sd/nsmp/Content/script/catalog_customization_files.htm) · [Система учёта заявок клиентов NAUMEN](https://www.naumen.ru/support/remote_access/)

## Как посмотреть Studio до согласования

Распакуйте архив проекта и откройте `demo/index.html` на своём компьютере. Демо работает на синтетических данных. Для запуска из таблицы настройте синхронное пользовательское действие с контекстом списка. [Кнопка «Аналитика» над таблицей](table-button.md)
