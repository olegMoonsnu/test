# Установка через «Каталог файлов кастомизации»

Для первого запуска нужен **один файл** — [скачать nsd-analytics-customization.js](https://github.com/olegMoonsnu/test/raw/refs/heads/nsd-customization/dist/nsd-analytics-customization.js). Если браузер открыл текст программы, сохраните его под этим именем с расширением `.js`.

1. В интерфейсе администратора на **тестовом стенде** откройте **Настройка системы → Каталог скриптов и модулей → Каталог файлов кастомизации**.
2. Нажмите **Добавить файл** и заполните форму.

   | Поле | Что выбрать или ввести |
   |---|---|
   | Название | NSD Analytics Studio |
   | Код | nsdAnalyticsStudio |
   | Файл | Скачанный nsd-analytics-customization.js |
   | Место применения | Интерфейс оператора |

3. Нажмите **Сохранить**. Откройте интерфейс **оператора** и обновите страницу.
4. Нажмите **Аналитика** внизу справа → **Открыть демо**. Должен появиться дашборд с **3 заявками** и **средним временем 60 минут**. Нажмите **Объекты**, чтобы увидеть три исходные строки, или **Esc**, чтобы вернуться в NSD.

## Как открыть свои данные

Если у вас есть разрешённая выгрузка в формате JSON, нажмите **Аналитика → Выбрать файл JSON**. Файл открывается в браузере. Допустимый размер — до 16 МиБ. Содержимое — массив объектов, например:

```json
[
  {"status": "В работе", "duration": 30},
  {"status": "Закрыта", "duration": 90}
]
```

Для автоматического открытия **текущей выборки NSD** нужна серверная операция. Она проверяет права пользователя на объекты и атрибуты, затем передаёт подготовленный массив в `NSDAnalytics.open(rows)` в том же клиентском окне. Загрузка файла кастомизации устанавливает Studio и кнопку. Сама кнопка не читает заявки из NSD. [Подключение серверной операции](nsd-integration.md)

## Если кнопка не появилась

Убедитесь, что на странице каталога есть запись с кодом `nsdAnalyticsStudio` и местом применения «Интерфейс оператора». Откройте новую вкладку именно с интерфейсом оператора. Если самого каталога или пункта «Интерфейс оператора» нет, понадобится скриншот **только меню или пустой формы** вашей сборки, чтобы уточнить путь. Данные заявок для этого не нужны.

## Как убрать кнопку

В том же каталоге удалите добавленную запись `nsdAnalyticsStudio` и обновите страницу оператора.

## Совместимость

Путь и поля формы приведены по актуальному публичному руководству SMP. NAUMEN указывает, что разработкой файлов кастомизации занимаются её специалисты. Эта сборка — вариант проекта для проверки на стенде. Работу самой сборки проверили в Chromium, доступ к установленной NSD 4.17 для проверки загрузчика отсутствовал. [Руководство NAUMEN, «Каталог файлов кастомизации»](https://www.naumen.ru/docs/sd/nsmp/Content/script/catalog_customization_files.htm)
