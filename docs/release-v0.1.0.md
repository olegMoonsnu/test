NSD Analytics Studio 0.1.0 — автономный аналитический виджет для разрешённых объектных выборок. Русский интерфейс, 18 представлений, фильтры AND/OR, статистика, сводная с пересчитанными итогами, drill-through и персональные дашборды.

- Для установки возьмите один из файлов `nsd-analytics*.js`. Он содержит CSS и вычислительный Worker.
- Для автономной демонстрации распакуйте архив и откройте `demo/index.html`.
- Инструкция подключения находится в `docs/nsd-integration.md`, результаты проверок и измерений — в `docs/performance.md` и `benchmarks/`.
- Проверено на синтетических данных. Привязка к штатной операции, права доступа и рабочий календарь требуют проверки в конкретной NSD 4.17.
