# Контракт данных и конфигурация

Каждый элемент массива — простой объект. Поддержаны строки, конечные числа IEEE 754, boolean, null, отсутствующие поля, массивы, DTO ссылок вида `{uuid,title}`, вложенные объекты. Объект Date при нормализации становится ISO-строкой. Несовместимые типы в одном поле получают mixed. Неконечные числа становятся null. Верхний предел строк, длины атрибута, глубины и сложности указан в [performance.md](performance.md).

Без columns схема объединяет ключи всех записей. Настроенная columns задаёт порядок, заголовки и белый список передаваемых в движок атрибутов. Параметр includeUnlisted явно включает остальные верхнеуровневые поля. Путь `owner.title` извлекает вложенное значение; точный собственный ключ с точкой имеет приоритет. Типы колонки: string, number, date, boolean, array, reference, object, mixed. Для пустой колонки по умолчанию используется string. Тип переопределяет интерпретацию и форматирование. Преобразуйте числовые строки в числа на стороне проекции, если планируются SUM или AVG.

Календарные даты задаются как YYYY-MM-DD, дата-время требует ISO со смещением или Z. Для типа date поддержаны epoch-миллисекунды. Автоопределение числовой даты ограничено полями с суффиксом At/Date/Дата и модулем значения от 10¹¹. Для остальных числовых дат укажите тип явно. Группировка day/week/month/year и календарная форма работают в UTC, неделя начинается в понедельник.

```js
const config = {
  title: 'Аналитика обращений', locale: 'ru-RU', theme: 'light',
  columns: [
    {code:'uuid',title:'UUID',type:'string'},
    {code:'status',title:'Статус',type:'string'},
    {code:'department',title:'Подразделение',type:'string'},
    {code:'duration',title:'Время решения',type:'number',unit:'мин'},
    {code:'createdAt',title:'Создано',type:'date'}
  ],
  widgets: [
    {id:'median',title:'Медиана решения',type:'kpi',measure:{op:'median',field:'duration'}},
    {id:'load',title:'Заявки по подразделениям',type:'bar',
     dims:['department','status'],measure:{op:'count'},limit:12,order:'desc'},
    {id:'trend',title:'Поступление',type:'line',
     dims:[{field:'createdAt',bucket:'week'}],order:'key',limit:30}
  ],
  pivot:{rows:['department','status'],cols:[],measures:[{op:'count'},{op:'avg',field:'duration'}]}
};
```

## Измерения, фильтры и визуализации

| Настройка | Значения и смысл |
|---|---|
| dims, pivot.rows, pivot.cols | Код поля или `{field,bucket,mode}`. Для простого графика первый уровень виден сразу, остальные доступны через «Следующий уровень». Для stacked/heatmap нужны два измерения. |
| mode | set — весь набор, повторения и порядок не меняют ключ; first — первое значение; explode — строка участвует один раз в каждой уникальной категории. Сумма категорий explode может превышать число объектов. Родительские и общие итоги сводной считаются по уникальному участию исходной строки. |
| measure | op и field; для count без поля считаются строки. У percentile параметр p от 0 до 1. До четырёх мер в сводной. |
| order, limit | key — сортировка по подписи, asc — BOTTOM N, desc — TOP N; N от 1 до 60. График сообщает о скрытых категориях. |
| transform | value, percent, cumulative, delta. Производные считаются после сортировки до ограничения N. |
| type | bar, column, pie, donut, line, stacked, area, heatmap, scatter, histogram, treemap, funnel, kpi, pareto, box, gauge, pivot, table. |
| x, y, goal | Для scatter нужны две числовые оси, для box/histogram — x. Для gauge нужна положительная цель goal. |
| span, height | 1 или 2. Изменяются в редакторе. Меню виджета перемещает его кнопками выше/ниже. KPI находятся в отдельной полосе. |
| filter | Узел `{join:'and'|'or',rules:[...]}` или условие `{field,op,value}`. Условия применяются глобально, на виджете и в сводной. |

Операторы фильтра: eq, ne, contains, notContains, starts, ends, gt, lt, gte, lte, between, in, notIn, filled, empty, dateRange, bool. between и dateRange принимают две границы включительно. Конечная дата без времени охватывает полный день UTC. Отрицательное условие многозначного атрибута истинно, если ни один элемент не подошёл. filled и empty проверяют весь атрибут. Текстовый поиск подстроки игнорирует регистр, равенство строк учитывает регистр. Пустая группа обозначает отсутствие ограничения. В редакторе значения списка разделяются запятыми, значения с запятыми можно передать в конфигурации массивом.

## Доверенные параметры хоста

| Параметр | Назначение |
|---|---|
| mount, fullscreen | DOM-контейнер или развёрнутое модальное окно с прежним URL. Элемент mount должен существовать. |
| urlField, onOpenObject | Поле ссылки (по умолчанию url) либо функция открытия разрешённого объекта. Callback получает проекцию DTO. |
| worker, nonce | worker:false принудительно включает главный поток. nonce назначается встроенному элементу style для политики хоста. |
| messages, locale | Словарь переводов с русскими ключами для надписей основного интерфейса и локаль Intl для чисел и дат. Собственные названия отчёта/полей/виджетов передаются отдельно. Поставляется русская локализация. Диагностические сообщения движка на русском. |
| storageKey, persistFilterFields | storageKey явно разрешает ручное локальное сохранение несекретной конфигурации по ключу профиля. Для хранения литералов фильтров требуется список разрешённых полей persistFilterFields. Без этих параметров доступны ручной экспорт и импорт файла. |

Значения фильтров и пользовательские заголовки могут содержать чувствительные сведения. Хост включает сохранение только для профилей с несекретными метаданными; на общем рабочем месте учитывайте пользователей одного browser origin.
