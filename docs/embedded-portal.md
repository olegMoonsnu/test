# Портал как встроенное приложение

Пакет для опытной установки на тестовом стенде NSD. Он содержит автономный каталог с демо-заявками и отдельную кнопку для перехода на штатную форму создания запроса. Сервер обслуживает приложение из загруженного архива.

1. Скачайте [smp-portal-demo.zip](../dist/smp-portal-demo.zip). Используйте сам ZIP.
2. В админке откройте **Настройка системы → Приложения → Добавить приложение**. Название — «Портал услуг (демо)», код — `smpPortalDemo`, тип — **Приложение, исполняемое на стороне клиента**. В поле «Файл приложения» выберите скачанный ZIP. Сохраните, затем нажмите **Включить** в карточке приложения.
3. В настройке тестового класса или типа откройте **Карточка объекта → Добавить контент → Встроенное приложение**. В поле «Приложение» выберите «Портал услуг (демо)», укажите вкладку и тестовый профиль, сохраните. Откройте объект под этим профилем в интерфейсе оператора.
4. Нажмите **Создать запрос в NSD**. Должна открыться штатная форма. Для проверки перехода закройте её без сохранения. Остальные кнопки каталога работают с вымышленными заявками в памяти. При недоступном JS API сверху появится сообщение.

Пакет собран по структуре публичного шаблона `@nsmp/create-app@3.1.1`: в корне ZIP лежат index.html и используемые им ресурсы. Для повторной сборки выполните `python3 scripts/build-portal.py`. Если тип запроса в вашей конфигурации имеет собственный FQN, используйте, например, `python3 scripts/build-portal.py --class-fqn 'serviceCall$request'`, подставив фактический код. Форма и право создания должны быть доступны текущему пользователю.

Открытая документация описывает клиентские ZIP как поставляемые Naumen. Архив проекта не подписан вендором. Допуск пользовательского архива, доступность JS API и права нужно проверить на конкретной сборке 4.17. Если стенд отклоняет ZIP, зафиксируйте точный текст ошибки и запросите у поддержки требования к пользовательским встроенным приложениям для этой сборки. Вкладка создаётся в интерфейсе оператора. Отдельный вход для заявителей и синхронизация раздела «Мои заявки» в эту версию не входят.
