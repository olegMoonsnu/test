# Модель доверия и проверка безопасности

Активы — разрешённые данные объектов, идентификаторы, ссылки и значения фильтров. Границы доверия проходят между операцией NSD, аргументом браузерного моста, импортируемым шаблоном и выгружаемым файлом. Браузер работает с уже переданным снимком; ограничение видимости графика не выполняет функцию авторизации.

| Участок | Реализация и проверка |
|---|---|
| Получение из NSD | Операция выполняет штатные проверки прав. Groovy-адаптер проверяет строку и поле перед чтением. Пример тестирует, что неразрешённое поле вообще не читается. |
| DTO и JSON | Разрешены простые данные. Глубина, число полей, размер строки, список и суммарный объём ограничены. Имена prototype, constructor и __proto__ запрещены в сегментах пути. Входные аксессоры отклоняются. Семантика доверенного JS API предполагает обычные объекты, не исполняемые Proxy. Строка payload обрабатывается JSON.parse. |
| DOM | Обычные элементы создаются через createElement/createElementNS; пользовательские значения задаются textContent или текстовым узлом. SVG-геометрия строится из чисел и фиксированного набора атрибутов. Для HTML-отчёта применяется отдельное HTML-экранирование и запрет скриптов в CSP. |
| Конфигурация | Данные проецируются в явную схему версии 1, проверяются имена, перечисления, размеры, глубина и ссылки на доступные поля. Импорт не допускает функций навигации, кода Worker, сетевых адресов и новых возможностей хоста. |
| Открытие карточки | URL проходит через URL parser, сравнение origin и разрешённые http/https; URL с credentials отклоняется. Новое окно открывается с noopener,noreferrer. Хост отвечает за переданный доверенный callback и проверку карточки на стороне сервера. |
| Хранение | Снимок принадлежит сессии в оперативной памяти. Локальное сохранение запускается пользователем и требует storageKey; литералы условий — дополнительного разрешения для поля. Проект не использует cookies, IndexedDB или сетевую телеметрию. |
| Экспорт | CSV/TSV получают UTF-8 BOM, текст в кавычках, удвоение кавычек и префикс-апостроф у подозрительного начала формулы. Это распространяется и на заголовки. Для clipboard дополнительно удаляются разделяющие табуляции и переводы строки внутри ячейки. Реальные отрицательные числа сохраняют тип числа. |
| Ресурсы | Worker получает фиксированный код из сборки. Блокировка blob Worker политикой CSP переводит работу в пакетный режим. При закрытии Worker завершается, окно удаляется. Политику организации не требуется ослаблять для сетевого доступа. |

В браузерных тестах проверены рендер HTML-подобной строки как текста, отклонение нежелательных URL и конфигураций, выгрузки, отсутствие HTTP(S)-запросов со страницы file:// и освобождение интерфейса. Аудит статического bundle проверяет отсутствие eval, new Function, fetch, XMLHttpRequest, WebSocket, sendBeacon и присваивания innerHTML.

Импорт файла и вручную инициированные выгрузки пересекают границу приложения: файл на диске и содержимое системного буфера остаются под управлением пользователя. При повторном импорте и сохранении CSV в сторонних табличных редакторах их правила обработки текста могут отличаться. Нативное копирование требует разрешения браузера. Встроенную политику CSP, навигацию и права конкретной NSD следует проверить на стенде.

Для сообщения об ошибке используйте синтетический пример по правилам [SECURITY.md](../SECURITY.md).
