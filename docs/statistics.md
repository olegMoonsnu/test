# Семантика расчётов

Единица наблюдения — входная строка. Даже при одинаковых UUID сохраняются обе строки. Для количества разных объектов выберите distinct по uuid. Пропуск, null, пустая строка и пустой массив считаются незаполненными. Ноль, false и строка из пробелов считаются заполненными. null и отсутствующее поле группируются вместе. Строки и числа имеют разные ключи, ссылочные DTO идентифицируются по UUID. Подпись ссылки берётся из title, если он передан.

| Операция | Определение |
|---|---|
| COUNT(*) | Число исходных строк, включая строки с пустыми атрибутами. На пустой выборке 0. |
| COUNT(field) | Число строк с заполненным полем. Значение-массив считается одной ячейкой. |
| COUNT DISTINCT | Число различных заполненных значений по типизированному ключу. Для массива ключ соответствует множеству его элементов. На пустой выборке 0. |
| SUM | Сумма конечных числовых значений с компенсацией погрешности сложения. |
| AVG | Среднее по числовым наблюдениям, обновляется по мере поступления значений. |
| MIN, MAX | Наименьшее и наибольшее числовое наблюдение. |
| MEDIAN | Квантиль 0,5. При чётном числе наблюдений используется среднее двух центральных. |
| PERCENTILE(p) | Отсортированный массив x, индекс h=(n−1)p. Между x[floor(h)] и x[ceil(h)] — линейная интерполяция с весом дробной части h. Допустимы p от 0 до 1. |
| MODE | Чаще всего встречающееся заполненное значение. При равенстве частот возвращается первое из встретившихся. Для текстовой моды подходят таблица, сводная и KPI. |
| VARIANCE | Дисперсия генеральной совокупности Σ(x−μ)²/n, однопроходный алгоритм Уэлфорда. Для одного значения 0. |
| STANDARD DEVIATION | Квадратный корень из дисперсии генеральной совокупности. |
| Доля | 100 × значение группы / сумму значений всех групп до TOP/BOTTOM N. При нулевом знаменателе — пусто. Для SUM со смешанными знаками возможны отрицательные доли. |
| Накопительный итог | Последовательная сумма в заданном порядке групп, до применения LIMIT. Для временных рядов используйте сортировку key и календарный интервал. |
| Динамика и относительное отклонение | 100 × (текущее − предыдущее) / abs(предыдущее). Для первой группы и при нулевой базе — пусто. |
| Сравнение периодов | Одна мера на двух выбранных диапазонах дат с одинаковыми общими фильтрами. Показываются оба результата, абсолютная разница и относительное отклонение. |
| Выбросы | Критерий Тьюки, IQR=Q3−Q1. Границы Q1−1,5×IQR и Q3+1,5×IQR. Усы идут до крайних наблюдений в пределах границ, отдельные точки — выбросы. |

Для числовых мер строки «12», boolean и содержимое массива не преобразуются в наблюдения автоматически. При отсутствии подходящих чисел или числовом переполнении результат пуст. Денежные вычисления с обязательной десятичной точностью требуют предварительного представления на сервере. Более 2⁵³−1 целые идентификаторы передавайте строками.

Сводная хранит отдельные аккумуляторы для ячеек, промежуточных итогов и общего итога. AVG, MEDIAN, DISTINCT и проценты итоговой строки рассчитываются по подходящим исходным строкам. SHARE и накопительный итог — преобразования обычных графиков. Круговая геометрия и линия Парето нормируются по показанным категориям. Стек поддерживает положительное и отрицательное накопление; Кольцо, Pie, Treemap, Funnel и Pareto требуют неотрицательных значений с положительным итогом.

Гистограмма использует до min(лимит, ceil(sqrt(n))) равных интервалов; последняя правая граница включена. Одна константная величина даёт одну корзину. Точки scatter выводятся детерминированной резервуарной выборкой до 500 пар. Ящик показывает счётчик всех выбросов и до 64 отдельных точек. При drill-through сводной передаются ключи выбранных префиксов и активные фильтры.
